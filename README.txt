DWTS Season 35 Pyramid

1. Open index.html in a browser to test it.
2. To put it online for free, create a free GitHub account at github.com.
3. Create a new public repository named dwts-pyramid.
4. Upload index.html.
5. In Settings > Pages, choose Deploy from a branch, select main, and save.
6. GitHub will give you a shareable website address.

The site works on phone and computer. Rankings are saved in that browser.
Use Save / Download to make a backup. The Add photos button lets you add contestant
photos from your device; name each image after the contestant (for example,
Julia Stiles.jpg) so the site can match it automatically.
